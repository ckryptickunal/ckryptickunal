## Open source

**[Founder Book](https://github.com/ckryptickunal/Founder-Book)** — A self-hostable LLM wiki built
from 1,500+ Y Combinator talks and Paul Graham / Sam Altman essays. Ask it anything in plain
English and get a cited answer instead of scrubbing through a 40-minute video. It keeps itself up
to date. *(Python, Gemini, RAG)*

**[Thumprint](https://github.com/ckryptickunal/cryptographic)** — Invisible watermarking for
AI-generated images and video. 82 ms to embed, imperceptible at 46–50 dB PSNR, and it survives
re-encoding, cropping and compression. Built for the provenance rules landing under EU AI Act
Article 50. *(Python, computer vision)*

**[PosterBoy](https://github.com/ckryptickunal/PosterBoy)** — Seven agents plan, compose, critique
and self-correct a poster until it's production-ready. You bring an image and an intent, it does
the rest. *(TypeScript, Gemini, multi-agent)*

**[NodeWow](https://github.com/ckryptickunal/NodeWow)** — Two-level LLM orchestration on a node
graph: decompose a multi-scene prompt, then generate every frame in parallel.
*(TypeScript, React Flow, BullMQ)*

**[Veo Prompt ML](https://github.com/ckryptickunal/veo-prompt-ml)** — Fine-tuned Flan-T5 extraction,
FAISS semantic search and a reward model for ranking video prompts. *(PyTorch, PEFT, FastAPI)*
